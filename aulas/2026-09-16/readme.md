# 1 Sistema de cadastro de livros

Desenvolva um sistema que permita gerenciar um coleção de livros. Todo livro deve ter os seguintes atributos: ISBN, título, autor e ano de publicação. O ISBN deve ser único para cada livro e não pode ser alterado
após o cadastro. Assim, é possível cadastrar livros com o mesmo título, autor ou ano de publicação, mas
não é permitido cadastrar dois livros com o mesmo ISBN. O sistema deve permitir ao usuário, por meio de
um menu, realizar as seguintes operações:

1. Cadastrar um livro;
2. Listar somente ISBN e título de todos os livros cadastrados;
3. Consultar um livro pelo ISBN e exibir seus dados
4. Consultar livros por autor e exibir somente ISBN e título;
5. Consultar livros por ano de publicação e exibir somente ISBN e título;
6. Atualizar os dados de um livro, exceto o ISBN;
7. Remover um livro;
8. Sair do sistema.
