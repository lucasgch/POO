# Introdução à linguagem Java

## Linguagem Java

  - Origem 1991 - Sun Microsystems
  - 1996 - Java é lançado oficialmente
  - A omnipresença em Java
    - Aplicações para Desktop (IRPF, Astah, IntelliJ)
    - Aplicações servidoras (Apache, Tomcat, JBoss, GlassFish)
    - Aplicações web (SIGAA)
    - Aplicativos android
    - Sistemas embarcados (Ginga SBTVD, SmartTVs, Smartcards)

## Características

  - Orientada a objetos
  - Robusta
    - Alocação dinâmica de memória e ponteiros
  - Neutro com relação à arquitetura
  - Independente de plataforma
  - Desempenho
    - Bytecode interpretado pela JVM
    - Workaround: Compiladores de bytecode "Just-in-time"
