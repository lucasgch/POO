# Map

Mapeia chaves para valores (key, value). Chaves são únicas e cada chave mapeia somente um valor.

```java
// chave: CPF, valor: Pessoa
HashMap<String, Pessoa> pessoas = new HashMap<>();
pessoas.put("123", new Pessoa("Juca", 35));
pessoas.put("456", new Pessoa("Maria", 20));
pessoas.put("789", new Pessoa("Ana", 31));
Pessoa p = pessoas.get("123"); // Obtém a pessoa associada à chave "123"
if (p != null) {
System.out.println(p);
}
// Iterando sobre chaves, valores e pares chave-valor usando forEach com lambda
pessoas.forEach((cpf, pessoa) -> {
System.out.println("CPF: " + cpf);
System.out.println("Nome: " + pessoa.getNome());
System.out.println("Idade: " + pessoa.getIdade());
});
```

## Iterando sobre chaves, valores e pares chave-valor

```java
// Iterando sobre chaves
for (String cpf : pessoas.keySet()) {
System.out.println("CPF: " + cpf);
}
// Iterando sobre valores
for (Pessoa pessoa : pessoas.values()) {
System.out.println("Nome: " + pessoa.getNome());
System.out.println("Idade: " + pessoa.getIdade());
}
// Iterando sobre pares chave-valor
for (var elemento : pessoas.entrySet()) {
System.out.println("CPF: " + elemento.getKey());
System.out.println("Nome: " + elemento.getValue().getNome());
System.out.println("Idade: " + elemento.getValue().getIdade());
}
```

## Removendo elementos

Remoção por chave

```java
HashMap<String, Pessoa> pessoas = new HashMap<>();
pessoas.put("123", new Pessoa("Juca", 35));
pessoas.put("456", new Pessoa("Maria", 20));
// Remove a pessoa associada à chave "123"
pessoas.remove("123");
```

Remoção por valor usando removeIf com lambda

```java
HashMap<String, Pessoa> pessoas = new HashMap<>();
pessoas.put("123", new Pessoa("Juca", 35));
pessoas.put("456", new Pessoa("Maria", 20));
// Remover todas as pessoas com o nome "Ana"
pessoas.values().removeIf(pessoa -> pessoa.getNome().equals("Ana"));
```
